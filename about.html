This website was created as a class assignment to practice building multi-page sites with plain HTML and CSS. The goal was to demonstrate headers, images, styled text, and working navigation between pages.

This version of the About page adds a two-column layout built with CSS Flexbox: a fixed-width navigation sidebar on the left and a flexible content area on the right, defined entirely in the external stylesheet style.css.

On smaller screens, the layout switches to a single column so the navigation sits above the content instead of beside it.
